# Battlezone

A faithful revival of a forgotten frontier - Classic vector tank combat game built with Next.js and Three.js.

## Features

- 🎮 Classic wireframe vector graphics
- 🌐 Multiplayer support via Firebase Realtime Database
- 💬 In-game chat
- 🗺️ Minimap
- ⚡ Power-ups (Shield, Rapid Fire, Health)
- 🎵 Sound effects with distance-based volume
- 📱 Touch controls for mobile

## Controls

- **W / Arrow Up** - Move forward
- **S / Arrow Down** - Move backward
- **A / Arrow Left** - Turn left
- **D / Arrow Right** - Turn right
- **Space** - Fire missile
- **Shift** - Sprint (while moving forward)
- **Ctrl + Shift + W** - Easter egg 🚀

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Deployment

This project is configured for easy deployment to Vercel:

1. Push to GitHub
2. Import to Vercel
3. Deploy

## Tech Stack

- [Next.js 15](https://nextjs.org/) with Turbopack
- [Three.js](https://threejs.org/) for 3D graphics
- [Firebase Realtime Database](https://firebase.google.com/) for multiplayer
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript
